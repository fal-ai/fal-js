Interface RealtimeExtension<Options, Session>

A customer-installable realtime protocol implementation.

The endpoint match is deliberately separate from open: fal owns endpoint selection and lifecycle, while the extension owns negotiation and the model-specific session API.

interface RealtimeExtension<Options, Session> {
    defaultEndpoint?: string;
    id: string;
    open(context: RealtimeExtensionContext, options: Options): Promise<Session>;
    supports(endpointId: string): boolean;
}
