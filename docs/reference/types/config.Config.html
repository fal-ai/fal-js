Type declaration

  • Optionalcredentials?: string | CredentialsResolver

    The credentials to use for the fal client. When using the client in the browser, it's recommended to use a proxy server to avoid exposing the credentials in the client's environment.

    By default it tries to use the FAL_KEY environment variable, when process.env is defined.

    See

    • https://fal.ai/docs/model-endpoints/server-side
    • #suppressLocalCredentialsWarning
  • Optionalfetch?: FetchType

    The fetch implementation to use for the client requests. By default it uses the global fetch function.

  • OptionalproxyUrl?: string | ProxyUrlConfig

    The proxy server to use for the client requests. The proxy server should forward the requests to the fal api.

    Pass a string for the common browser-only case — the middleware rewrites requests to this URL when a DOM window is available and does nothing otherwise (the default, recommended for standard web apps).

    Pass a ProxyUrlConfig object to opt into non-browser runtimes (Electron, server, edge/worker, Bun, etc.) via the when gate.

    Example: Browser-only (unchanged behavior):

    fal.config({ proxyUrl: "/api/fal/proxy" });

    Example: Always apply, regardless of runtime:

    fal.config({
      proxyUrl: { url: "/api/fal/proxy", when: "always" },
    });

    Example: Custom predicate (e.g. Electron renderer only):

    fal.config({
      proxyUrl: {
        url: "/api/fal/proxy",
        when: ({ isBrowser }) => isBrowser || process.type === "renderer",
      },
    });
  • OptionalrequestMiddleware?: RequestMiddleware

    The request middleware to use for the client requests. By default it doesn't apply any middleware.

  • OptionalresponseHandler?: ResponseHandler<any>

    The response handler to use for the client requests. By default it uses a built-in response handler that returns the JSON response.

  • Optionalretry?: Partial<RetryOptions>

    Retry configuration for handling transient errors like rate limiting and server errors. When not specified, a default retry configuration is used.

  • OptionalsuppressLocalCredentialsWarning?: boolean

    Suppresses the warning when the fal credentials are exposed in the browser's environment. Make sure you understand the security implications before enabling this option.
